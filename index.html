Личное приложение · один владелец

Резервные копии Князь-бота в Google Drive

KnyazBot Drive Backup предназначено для сохранения проверенных локальных копий данных проекта в личном Google Drive владельца. Это служебный инструмент, а не общедоступный сервис.

Как используются данные ↗

Как это устроено

Копия проверяется до и после загрузки

01

Локальный снимок

Отправляется только подготовленная и проверенная резервная копия, выбранная владельцем для удалённого хранения.

02

Шифрование до передачи

restic шифрует копию на устройстве владельца. rclone передаёт в Google Drive уже зашифрованные файлы.

03

Проверка и хранение

После загрузки предусмотрены проверка данных и пробное восстановление. Старые версии удаляются по политике хранения только после успешной проверки.

Доступ к Google Drive

Только для резервных копий владельца

Для подключения планируется минимальное разрешение drive.file, позволяющее приложению работать с созданными им файлами. Его пригодность для загрузки, проверки, восстановления и удаления копий будет проверена при настройке. Приложение не предназначено для чтения остальных файлов Google Drive.

Условия использования

Приложение создано для личного использования одним владельцем и не предлагает регистрацию, услуги или доступ третьим лицам. Для работы требуются личный Google-аккаунт владельца, его явное согласие на доступ к Drive и отдельно сохранённый пароль шифрования. Владелец может в любой момент прекратить использование, отозвать разрешение Google и удалить свои копии.
